# Phase1 multi-provider foundation

Deliver Codex and Gemini model workers above existing CDC native authority.
The owner deferred real Gemini connection: current delivery is code,
deterministic native-process evidence, operator examples and a canonical
draft PR. Live model acceptance and production adoption are separate.

A strict cdc-agent-task/v1 envelope binds original project/repository/base,
native task/worktree/branch, objective/criteria, allowed operations/files,
provider/model, security, budget, timeout, dependencies, checks, review and
artifacts. It grants no authority. Retain exact native runtime/store/backend,
original charged model reservation and launch CAS. No automatic retry/resume,
fallback, account rotation, database or competing controller. Preserve v1
records and all original UNKNOWN liabilities.

Native ownership, worktrees, conflicts, dependencies, cancellation, physical
closure and persistent original-attempt recovery remain authoritative. Strict
provider terminal evidence and actual deterministic commands/exits/log refs
gate execution success. Unknown usage remains null.

A checked scoped developer commit is independently reviewed at the exact
proposed head through the opposite provider. The reviewer receives the actual
base/head diff and authenticated developer test evidence, owns no write paths
and declares required_tests empty. Complete receipts, strict verdict shape and
an unchanged raw Git snapshot gate approval. Provider evidence grants no
acceptance/integration/release/publication authority; one review round grants
no implicit correction retry.

Initial material is synthetic/public only. Later live operation needs actual
provider eligibility and host-qualified OS/profile isolation. CLI approval
modes are not an OS sandbox. The optional Antigravity variant is an unadopted
technical prototype; Google does not support consumer wrapping inside third-party
agent applications. Keep credentials and private operational history out of
public source.

Qualify both developer→commit→opposite-reviewer directions, parallel isolation,
conflicting claims, timeout/cancel, unavailability and in-flight reconstruction
with synthetic CLIs and real Git/process/native CAS. Use hosted targeted checks
and one exact FULL/bootstrap/package/projection gate. Preserve existing version,
release driver lock and installed consumers. No release or deployment is made.
