Add package templates, fault scenarios, references, validator coverage and 2.11.3 version/source-lock/consumer-snapshot bindings. Run repository layout, independent bootstrap, package validation, full unit tests and three archived consumer validation in PR CI.

## Task 5 — review/release

Perform specification compliance then code-quality review. Resolve material findings, freeze exact source, rerun release validation, generate release evidence, then and only then create immutable release identity. Live consumer rollout remains a separate post-release scope.
